# Dataset

**Dataset:** Wizard of Oz

The model is trained using a character-level representation of the text. Every unique character is assigned an integer ID before being converted into learned embeddings.

# Training Pipeline

The training process follows these steps:

1. Read the raw text dataset.
2. Build the vocabulary.
3. Encode the text into token IDs.
4. Split the dataset into training and validation sets.
5. Generate mini-batches.
6. Perform a forward pass through the GPT model.
7. Compute Cross Entropy Loss.
8. Perform backpropagation.
9. Update model parameters using AdamW.
10. Repeat for multiple iterations.

# What This Project Demonstrates

This project implements the core components of a GPT-style language model from scratch, including:

* Character-level tokenization
* Learned token embeddings
* Learned positional embeddings
* Masked self-attention
* Multi-head attention
* Feed-forward neural network
* Layer normalization
* Residual connections
* Transformer blocks
* Autoregressive text generation

---

# Limitations

This implementation is intentionally educational.

Compared to modern production LLMs, it does **not** include:

* Byte Pair Encoding (BPE)
* Rotary positional embeddings (RoPE)
* Flash Attention
* Dropout
* Mixed precision training
* Learning rate scheduling
* Large-scale distributed training
* Billions of parameters

These improvements are planned for Version 2.
