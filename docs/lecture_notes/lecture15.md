# Lecture 15 - What is a Language Model?

## Key Ideas

- A tokenizer prepares data.
- A dataset creates input-target pairs.
- A model is the part that learns.
- The model stores knowledge in parameters.
- A Bigram model predicts the next token using only the current token.
